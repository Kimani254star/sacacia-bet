Build · 19 Nov 2026

Flashscore feed integration

Latest app update

Added

  • Added a Flashscore feed adapter for fixtures and results, designed to receive normalized data from a server-side feed endpoint.
  • Added event status, start time and score fields to the feed display.
  • Added five-minute refresh polling and stale-feed/error status handling.
  • Added a dedicated in-app Build Log page and navigation links.

Fixed / improved

  • Feed content is rendered as text with HTML escaping rather than inserting provider values as markup.
  • Provider credentials are not placed in browser-side JavaScript.
  • Updated the offline app shell to include the feed integration and this Build Log page.

Notes

Live Flashscore data is not active yet. Acacia Bet still needs an authorized data provider/API, a deployed server-side endpoint (for example, a Supabase Edge Function), and its secret configured on the server. The feed URL is intentionally blank until that setup is completed. This build does not scrape Flashscore pages or invent fixtures and scores.
Build · Previous updates

App logging and production-data safeguards

Added

  • Added the Activity Logs screen with on-device event history and CSV export.
  • Added a clear-logs action and a notice that passwords and form contents are not recorded.
  • Added production-data safeguards so demo fixtures and simulated prices are not presented as verified live data.

Notes

  • Activity Logs record actions on the current device; they are distinct from this release Build Log.
  • Payment, betting settlement and live sports-data services require their own authorized production integrations and configuration.
